# crypto-gold-report

每日加密货币与黄金市场资讯晨间报告生成工具，基于 OpenClaw 平台运行。

## 功能

- 自动生成比特币（BTC）晨间报告
- 自动生成黄金（XAU）市场报告
- 动态搜索全网数据源，关键词基于当前日期自动生成
- 三轮扩展搜索策略（基础 → 扩展关键词 → 站内搜索），时间窗口固定 12 小时不放宽
- 标题相似度 > 70% 自动去重，按来源权威性排序
- 集成恐惧贪婪指数（Fear & Greed Index）
- 趋势分析必须引用具体资讯来源，不得凭空推测

## 平台与工具

- **平台**: OpenClaw（非 Claude Code）
- **触发方式**: cron 定时任务
- **核心工具**:
  - `WebSearch`: 搜索资讯和行情数据
  - `mcp__web_reader__webReader`: 提取网页详细内容

## 报告内容

### 比特币报告
- BTC/USD 价格、24h 涨跌幅、24h 成交量
- 恐惧贪婪指数
- 利好/利空资讯（表格格式，含来源+链接+精确时间）
- 趋势分析（引用具体来源）
- 多周期趋势预测（24h/3d/7d/1m）

### 黄金报告
- 国际金价、国内足金、基础金价、投资金条价格
- 恐惧贪婪指数
- 利好/利空资讯（表格格式）
- 趋势分析（引用具体来源）
- 多周期趋势预测

## 输出规则

- 资讯发布时间不超过 12 小时，超时丢弃
- 每条资讯含：标题 + 来源 + 链接 + 发布时间（精确到分钟）
- 同一事件去重，按来源权威性保留（金十 > 新浪 > CoinDesk/Kitco > 其他）
- 趋势预测必须引用具体资讯来源
- 不足时不凑数不编造，标注实际获取数量
