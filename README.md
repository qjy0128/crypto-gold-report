# crypto-gold-report

每日加密货币与黄金市场资讯报告生成工具，基于 OpenClaw 平台运行。

## 功能

- 自动生成比特币（BTC）市场报告和黄金（XAU）市场报告
- 五阶段流程：数据采集（并行） → 资讯处理 → 补充搜索 → 生成报告 → 质量自检
- 三轮扩展搜索策略（基础 → 扩展关键词 → 站内搜索），时间窗口固定 12 小时
- 自动去重（同一事件/相同链接/高度相似标题），按来源权威性排序
- 集成恐惧贪婪指数（Fear & Greed Index）
- 质量自检清单确保报告完整性和准确性

## 平台与工具

- **平台**: OpenClaw（非 Claude Code）
- **触发方式**: cron 定时任务
- **核心工具**:
  - `WebSearch`: 搜索资讯和行情数据
  - `mcp__web_reader__webReader`: 提取网页详细内容

## 执行流程

```
Phase 1A (并行): 获取实时价格 + 恐惧贪婪指数
Phase 1B (并行): 搜索资讯 + 宏观背景（至少8组）
Phase 2: 提取详情 → 时间过滤(12h) → 去重 → 分类
Phase 3: 补充搜索（利好/利空不足5条时）
Phase 4: 填充报告模板
Phase 5: 质量自检清单
```

## 核心规则

- **价格铁律**：所有价格必须实时抓取，失败显示 N/A，绝不编造
- **资讯铁律**：禁止编造标题/来源/时间，必须来自实际搜索结果
- **来源铁律**：禁止用"综合判断"等非真实来源充当资讯来源
- **备用源铁律**：主源失败必须尝试全部备用源，全部失败才可标 N/A
- **时效性**：仅保留 12 小时内资讯，发布时间必须精确到分钟
- **补充搜索**：资讯不足5条必须执行三轮搜索，不可跳过直接发布
- **去重**：同一事件仅保留一条，按权威性优先
- **可追溯**：趋势分析/预测必须引用具体资讯来源
